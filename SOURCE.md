Source code for this signing service
====================================

This service is DocuSeal, open-source document signing software from
DocuSeal LLC, with Startr LLC's branding changes. It runs at
https://seal.startr.cloud.

- DocuSeal source: https://github.com/docusealco/docuseal at tag 3.0.3
- Startr's changes: https://github.com/Startr/docuseal-startr at tag
  v3.0.3-startr.1
- Licence: GNU Affero General Public License v3, with one additional term
  under section 7(b): a covered work must keep the original DocuSeal
  attribution in interactive user interfaces.

The changes are small. Seven page templates show the Startr mark and name
beside a "powered by DocuSeal" credit. One stylesheet sets Startr's colours
and font. The favicons are Startr's. Every other file is DocuSeal's own.
